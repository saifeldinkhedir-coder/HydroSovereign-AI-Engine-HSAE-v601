# HSAE v6.01 QGIS Plugin

**HydroSovereign AI Engine v6.01** — Complete QGIS Plugin

## Installation

1. Download `HSAE_v601_QGIS_Plugin_FINAL.zip`
2. QGIS -> Plugins -> Manage -> Install from ZIP
3. Select the downloaded zip

## Features

- 13 Tools: Basin Registry, TDI Visualiser, UNWC Legal Layer,
  GEE Scripts (7 sensors), GRDC Stations, Conflict Index,
  Negotiation AI, WebGIS Map, Dashboard Panel, ICJ/PCA Dossier
- 5 Processing Algorithms: ATDI, HIFD, Basin Report,
  HBV-96 Calibration (SCE-UA), Multi-Basin Comparison
- 26 transboundary basins with real geopolitical data (TFDD/ICOW)
